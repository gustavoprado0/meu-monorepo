# 🚀 Meu Monorepo

Monorepo para desenvolvimento e gerenciamento de múltiplas aplicações utilizando uma base compartilhada de componentes, configurações e ferramentas.

A estrutura permite manter diferentes aplicações dentro do mesmo repositório, compartilhando código e configurações entre elas.

## 📦 Estrutura do projeto

```text
meu-monorepo/
│
├── apps/
│   ├── admin/
│   └── web/
│
├── packages/
│   ├── config/
│   └── ui/
│
├── .yarn/
├── package.json
├── yarn.lock
└── README.md
